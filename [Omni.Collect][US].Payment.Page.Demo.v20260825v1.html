Omni Collect Payment Page Demo for US Market v.20260825

NOTE: Must use Stripe API version 2026-07-29.dahlia. Create the Checkout Session with ui_mode=embedded_page for Embedded Checkout or ui_mode=elements for Stripe Elements.

Making Payment via Embedded Checkout

Step 1: Enter Publishable Key & Client Secret
Use the publishable key from the same Stripe account that created the Checkout Session. The Client Secret must come from a Checkout Session created with ui_mode=embedded.
Step 2: Embedded Checkout

Making Payment via Stripe Elements

Step 1: Enter Publishable Key & Client Secret
Use the publishable key from the same Stripe account that created the Checkout Session. The Client Secret must come from a Checkout Session created with ui_mode=elements.
Step 2: Payment Element

Stripe Elements with Custom Payment Method

Step 1: Enter Stripe Details
This tab uses the Payment Intents API + Stripe Payment Element. The Client Secret must come from the Stripe PaymentIntent created for this payment. The Custom Payment Method ID is the cpmt_... ID created in Stripe Dashboard.
Step 2: Select Payment Method
Select POC ACH, then click Continue / Pay. The demo uses Stripe elements.submit() to identify the selected Custom Payment Method and hand the flow from Stripe to Omni Collect.

HSBC ACH - Omni Collect / Plaid Handoff

Step 3: Make Backend Plaid API through Omni Collect
Make the Plaid backend API call separately through Omni Collect, then paste the returned link_token below.
