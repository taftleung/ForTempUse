Making Payment via Stripe Elements

Stripe Elements with Custom Payment Method

Step 1: Enter Stripe Details
This tab uses the Payment Intents API + Stripe Payment Element. The Client Secret must come from the Stripe PaymentIntent created for this payment. The Custom Payment Method ID is the cpmt_... ID created in Stripe Dashboard.
Step 2: Select Payment Method
Select POC ACH, then click Continue / Pay. The demo uses Stripe elements.submit() to identify the selected Custom Payment Method and hand the flow from Stripe to Omni Collect.
